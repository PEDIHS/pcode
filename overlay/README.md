# Jcode Windows overlay (پراکسی MCP برای Windows-MCP)

`proxy.py` یک پراکسی MCP روی stdio است که همه ابزارهای Windows-MCP را بدون تغییر عبور
می‌دهد و هنگام کار ایجنت روی دسکتاپ یک لایه شفاف، همیشه‌رو و عبورپذیر برای کلیک
(`overlay.py`) نشان می‌دهد:

- حاشیه بنفش درخشان دور هر مانیتور (نبض آرام هنگام کار)
- نشانگر بنفش جدا با برچسب «Jcode» که تا محل Click/Move/Type/Scroll می‌لغزد؛ کلیک با موج
- دکمه کوچک «توقف ایجنت Jcode · Esc» بالای مانیتور اصلی
- بعد از ۴ ثانیه بی‌کاری محو می‌شود (`JCODE_OVERLAY_IDLE`)
- هنگام Screenshot/Snapshot پنهان می‌شود تا ایجنت صفحه واقعی را ببیند
  (`JCODE_OVERLAY_IN_CAPTURE=1` برای نگه‌داشتن)

## توقف

کلید **Esc** واقعی (نه Esc که خود ایجنت می‌فرستد) یا کلیک واقعی روی دکمه توقف:
همه فراخوانی‌های در جریان با خطای «کاربر متوقف کرد» برمی‌گردند و در Windows-MCP لغو
می‌شوند، و تا ۶۰ ثانیه (`JCODE_STOP_SECONDS`) کارهای دسکتاپ (کلیک، تایپ، اجرای برنامه،
کلیدمیانبر، کلیپ‌بورد) رد می‌شوند تا ایجنت بایستد و از شما بپرسد. Esc به برنامه‌ها هم
می‌رسد (بلعیده نمی‌شود)؛ کلیک روی دکمه توقف به برنامه زیر آن نمی‌رسد.

## اجرا

```
python proxy.py -- uvx --python 3.13 windows-mcp serve --transport stdio
```

مدخل `windows-overlay` در `~/.jcode/mcp.json` همین را اجرا می‌کند. لاگ:
`D:\jcode-build\jcode-windows-overlay\overlay.log`. تصاویر حاشیه در
`%LOCALAPPDATA%\JcodeOverlay\cache` نگه داشته می‌شوند تا شروع سریع باشد.

نیازها: Python 3.12 با Pillow و numpy (همین حالا نصب‌اند). Windows-MCP (MIT) جداگانه با
uvx اجرا می‌شود و تغییری در آن داده نشده.
