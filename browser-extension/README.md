# Jcode Browser Agent (افزونه کروم)

افزونه‌ای که به Jcode اجازه می‌دهد در تب‌های خودش در کروم کار کند، مثل افزونه
Claude in Chrome. پایه آن افزونه متن‌باز Playwright (Apache-2.0) است؛ جزئیات در
`THIRD_PARTY_NOTICES.md`.

## چه کار می‌کند

- ایجنت فقط در تب‌های گروه بنفش **«Jcode»** کار می‌کند؛ پیش‌فرض در یک پنجره جداگانه
  (اگر مانیتور دوم دارید، روی همان) تا تب‌های شما دست نخورد.
- روی تب تحت کنترل: حاشیه بنفش متحرک، برچسب «Jcode روی این تب کار می‌کند»، و یک
  نشانگر موس بنفش که تا محل کلیک می‌لغزد و کلیک را با موج نشان می‌دهد؛ هنگام تایپ
  برچسب «typing…» می‌گیرد.
- آیکن افزونه (popup): وضعیت اتصال، فهرست تب‌های ایجنت، دکمه **«توقف فوری»**. بعد از
  توقف، اتصال خودکار بسته می‌ماند تا خودتان «ادامه کار ایجنت» را بزنید.
- کروم بالای صفحه نوار «Jcode Browser Agent started debugging this browser» نشان
  می‌دهد؛ دکمه Cancel آن هم کنترل را قطع می‌کند.

## نصب (Load unpacked)

1. در کروم بروید به `chrome://extensions`.
2. بالا سمت راست **Developer mode** را روشن کنید.
3. **Load unpacked** را بزنید و پوشه `D:\jcode-build\jcode-browser-extension` را انتخاب کنید.
4. شناسه افزونه باید `jmnejhlgjkioenaidflmjohpgcohbbli` باشد.
5. (اختیاری) از آیکن پازل، Jcode Browser Agent را سنجاق (pin) کنید.

سمت Jcode، سرور MCP با نام `jcode-browser` در `~/.jcode/mcp.json` است
(`D:\jcode-build\jcode-browser-mcp\launch.cjs`، همان Playwright MCP در حالت `--extension`).
توکن مشترک در `config.json` همین پوشه است؛ آن را پخش نکنید.

## تنظیمات در popup

- کار در پنجره جداگانه (پیش‌فرض روشن)
- نمایش حاشیه و نشانگر بنفش (پیش‌فرض روشن)
- اگر پنجره ایجنت کاملاً پوشیده شد، هنگام کار جلو بیاید (پیش‌فرض روشن). کروم صفحه‌ای را
  که کاملاً زیر پنجره‌های دیگر است متوقف می‌کند و کلیک‌ها گیر می‌کنند؛ این گزینه فقط
  در آن حالت پنجره ایجنت را جلو می‌آورد.
